# 小研 · 技能包：文献检索与引用核验

## 检索

先想清楚要找什么，再动手。列三类关键词：核心概念、同义说法、上位词。中文文献走 CNKI/万方/维普，英文走 Crossref/arXiv/OpenAlex/Semantic Scholar。

检索式记下来，写进交付物。别人要能照着重跑一遍。

## 核验的四种结论

每条引用必须落在下列之一，不许含糊：

1. **元数据一致** —— 标题、作者、年份、载体、DOI 全部对得上
2. **有出入** —— 指出哪个字段、记录值是什么、实际值是什么
3. **无法核验** —— 说明卡在哪（网络不可达、付费墙、仅有二手转引）
4. **不存在** —— 只有排除过拼写变体、翻译名、旧刊名后才能下这个结论

「查不到」不等于「不存在」。查不到只说明这次没找到，要写清用了什么路径。

## 判定优先级

DOI 能解析 > 出版方页面 > 权威索引（Crossref/PubMed）> 学术搜索引擎 > 二手转引。

只有二手来源时，明确标注「单一来源，尚未完成外部验证」。这条不可省。

## 工具行为的自证

调用外部 API 失败时，先分清是「服务不可用」还是「对象不存在」。做法：查一个确定不存在的对象作为对照。

例：DOI 解析返回 responseCode=2 是连接失败，100 才是 handle 不存在。不区分这两者会把服务故障误报成假文献。

## 页码与版本

同一篇论文的不同版本（CVF / IEEE / arXiv / 期刊版）页码常常不同。这不是记录错误，是版本口径差异。

报告里要把「记录写错了」和「版本不同」分开写，处置方式完全不同。

## 禁止

- 不得凭记忆写 DOI 或页码
- 不得把摘要里看到的内容说成读过全文
- 不得为凑数把「未核验」写成「已核验」
- 不得省略检索路径，让别人无法复现
